✅ QA Agent

Auditing already-closed cases — augmenting human reviewers, never replacing them.

Plain English: After a case is closed, this agent reviews it like a quality control auditor. It is deliberately separate from the Verification Agent: Verification runs during the live case and can change the outcome; the QA Agent runs afterwards, on already-closed cases, and can only flag them for a human auditor to look at — it never reopens a case or changes any decision on its own. It catches documentation gaps, weak conclusions, and verification overrides that weren't properly recorded.
