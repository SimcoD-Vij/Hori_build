🚦 Triage Agent

The first decision: can we call the customer, or must we stay silent?

Plain English: This agent reads all the fraud flags on an account and decides one thing: is it legally safe to call the customer? If the pattern looks like money laundering (AML), calling them would break the law — it's called "tipping-off" and it's a criminal offence. So those cases get routed silently to investigators. Only fraud cases (like a stolen card or account takeover) are safe to contact the customer about directly.

Hard rule: Under any ambiguity, the agent always picks AML_BRANCH. It would rather be overcautious than accidentally tip off a money launderer.
