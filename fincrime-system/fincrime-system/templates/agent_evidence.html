🔍 Evidence Agent

Compiling everything we actually know about a suspicious account.

Plain English: Before any investigation can proceed, someone needs to gather the facts. This agent pulls together: the specific flags that triggered the alert (with exact evidence text), a real-time check against international sanctions lists (OpenSanctions), how old the account is, and whether other accounts share the same identity. It packages all of this into one structured evidence packet that every downstream agent reads from. Nothing is invented — if it is not in the data, it is not in the packet.

What the Evidence Packet Contains
🚩Flags — exact rule name + evidence text + transaction IDs
📋Sources — deduplicated list of detection engines that flagged this account
🌐Sanctions — OpenSanctions hit/miss + confidence score
🔗Linked Accounts — other accounts sharing the same hashed identity
📅Account Age — days since opening (new accounts = higher risk)
LangGraph Role

Evidence Agent is a peer node — it runs immediately after Triage on both branches. Its output populates the evidence key in the shared FincaseState, which the Risk Assessment Agent, Explanation Agent, and Verification Agent all read from. It does not wait for Risk Assessment and Risk does not wait for it in the graph — they are concurrent.
