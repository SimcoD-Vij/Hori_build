📞 Voice AI Agent

HITL — Human approval required AML cases: refused by design

Preparing verification calls — powered by Dograh, PocketTTS, and Ollama.

Plain English: This agent only activates on fraud cases — it is physically incapable of running on an AML case (doing so would be illegal tipping-off). When activated, it selects the right set of verification questions based on the fraud type, then hands off to the investigator. The investigator must click "Approve Call" — the AI never dials automatically. Once approved, the call routes through Dograh, which uses a real-time STT/TTS pipeline and an Ollama LLM to handle the conversation.
