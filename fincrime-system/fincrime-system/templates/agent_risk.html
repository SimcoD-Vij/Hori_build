📊 Risk Assessment Agent

How dangerous is this case, really? Matching evidence to known crime patterns.

Plain English: This agent takes the evidence packet and asks: does this look like a known crime pattern? It checks against a library of typologies — structuring, bust-out fraud, account takeover, wire fraud, synthetic identity rings, and more. If it finds a confident match, it names the pattern and scores the severity 1–10. If nothing matches, it labels the case NOVEL_PATTERN — which automatically routes it to a human investigator, because something new and unclassified is always worth a real person looking at. It now also breaks risk into three dimensions: rule-based signals, graph-network signals, and statistical signals.

LangGraph Role

Risk Assessment is a peer node running concurrently with Evidence in the graph. Its output (dimension_scores, matched_typology, severity) is read by Explanation Agent and the Verification Supervisor. The branch_hint it returns re-confirms Triage's routing decision — any disagreement surfaces at the Verification node.
