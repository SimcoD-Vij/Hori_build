🛡️ Verification Agent

SUPERVISOR NODE — override authority

The system's safety net: an independent second pass that can override every earlier agent.

Plain English: After every other agent has made its decisions, this agent reads the full case from scratch — completely independently — and checks for contradictions. Does the report cite evidence sources that don't exist? Is a severity-9 case only being "monitored"? Did a novel pattern get automatically closed without human review? If it finds any of these problems, its FAIL verdict overrides everything that came before it, no matter what earlier agents concluded. This override is not configurable from outside this file.
